## 修复的主要问题

1. **依赖漏洞**：Werkzeug 3.1.8 在 Windows 上允许特殊设备名文件路径，可能导致读取挂起；升级到 3.1.9。[官方公告](https://github.com/pallets/werkzeug/security/advisories/GHSA-g6x2-hccm-hh4m)，扫描原始结果与更新结果均按当时联网数据核对，最新机器报告为 dependency-audit.json。
2. **登录重放**：原本只靠签名 Cookie 中的管理员 ID，退出或改密码无法撤销旧 Cookie。现在使用数据库会话摘要、固定有效期、闲置超时及撤销。
3. **生产配置缺口**：明确区分本机预览与生产；缺少安全配置时拒绝启动，加入 Host 限制和显式代理数量。
4. **图片访问范围**：原来上传目录内文件可直接访问。现在只接受随机图片文件名，并检查公开内容、工作人员或订单所有者权限。
5. **上传一致性**：统一海报、成员照片、收款码和相册的格式、单文件大小、像素及 EXIF 清除；保存失败时移除本次临时文件，保留旧内容。
6. **错误与滥用**：限流返回 Retry-After，未知账号与错误查询使用同类哈希检查，非法 Unicode CSRF 不产生异常；数据库故障返回受控页面，超大数字 ID 在路由阶段拒绝。
7. **备份与维护**：完整备份不覆盖目标，包含图片和校验清单，检查数据库完整性和外键；订单增加分页，编辑库存时在事务内读取当前场次状态。
8. **网站完整性**：隐私说明、公开页面元数据、robots 与只包含公开非测试演出的站点地图；更新照片管理提示、部署文档、代码格式与 CI 模板。
